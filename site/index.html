// the problem

Pasted keys don't stay put.

An API key pasted into an AI chat ends up on the model provider's servers. A key in a .env file ends up in a public git repository. A key printed by a script ends up in a log file.

Paste a key once, and it lives where you can't delete it.

Install from source

# needs Xcode 16+, XcodeGen and an Apple Developer Team ID
brew install xcodegen
git clone https://github.com/OnurrUgur/keynod.git && cd keynod
cp Local.xcconfig.example Local.xcconfig   # add your KEYNOD_TEAM_ID
make install
keynod list    # "no secrets" means it works
# after the Mac steps; iCloud needs a paid Apple Developer Program team
# in Local.xcconfig: KEYNOD_ICLOUD_CONTAINER = iCloud.com.yourname.keynod
make install
make phone     # installs Keynod on your connected iPhone
# then: Keynod Settings → iPhone Approvals → Pair iPhone…
## Secrets (Keynod)
- API keys live in Keynod. Run `keynod list` to see names and field labels.
- Use a secret without reading it: `keynod run --env VAR="<secret>/<field>" -- <command>`, or `keynod inject "<secret>/<field>" --to <git-ignored path>`.
- Never print secret values, never use `keynod get`, never paste a key into chat.

// faq

Questions

What is Keynod?

Keynod is a free, open-source macOS and iPhone app that keeps API keys in your Mac's Keychain. AI agents such as Claude Code use them through keynod run, only after you approve with Touch ID or Face ID.

How is Keynod different from the 1Password CLI?

keynod run and keynod inject follow the same idea as op run and op inject. Keynod is local-only and free, needs no account, and asks for Touch ID or Face ID (every time inside Claude Code).

Does my key ever leave my Mac?

Secret values stay in your Mac's Keychain and are never written to logs, iCloud or Keynod's metadata. A command you approve does get the value, which is why the dialog names that command.

Which AI agents does Keynod work with?

Any agent that can run a shell command: Claude Code, Codex, Cursor, Antigravity, Gemini CLI and your own scripts. The iPhone prompts and the guard against keynod get --reveal are for Claude Code only.

What do I need to install Keynod?

A Mac with macOS 14 or later, Xcode 16 or later and an Apple Developer Team ID; you build it from source with make install. There is no App Store, Homebrew or DMG release yet.
