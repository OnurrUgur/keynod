# Code of Conduct

Be kind, assume good faith, and keep discussions about the work.

Not accepted here: harassment, insults, personal attacks, discriminatory language, publishing someone's private information, and sharing anyone's secrets or credentials.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block people who keep breaking them. To report a problem privately, use GitHub's "Report content" option or contact the maintainers through a Security Advisory if it concerns a person's safety or data.
